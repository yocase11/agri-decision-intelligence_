Basic Forecast Metrics

These metrics are commonly used in regression and time-series forecasting to evaluate average error and variance.

Metric Definition Formula Interpretation
MAE Mean Absolute Error MAE = (1/n) * Σ |yᵢ - ŷᵢ| Average magnitude of forecast errors, easy to interpret in original units.
MSE Mean Squared Error MSE = (1/n) * Σ (yᵢ - ŷᵢ)² Penalizes larger errors, useful for optimization and loss functions.
RMSE Root Mean Squared Error RMSE = sqrt(MSE) Root-scaled error that is comparable to the units of the target variable.
MAPE Mean Absolute Percentage Error MAPE = (100/n) * Σ |(yᵢ - ŷᵢ) / yᵢ| Relative error in percent; sensitive when actual values are near zero.

Intermediate Forecast Metrics

These metrics provide scale-independent measures and improved handling of skewed forecast distributions.

Metric Definition Formula Interpretation
SMAPE Symmetric Mean Absolute Percentage Error SMAPE = (100/n) * Σ (|yᵢ - ŷᵢ| / ((|yᵢ| + |ŷᵢ|) / 2)) Symmetric percentage error that reduces bias for small actual values.
RMSLE Root Mean Squared Log Error RMSLE = sqrt((1/n) * Σ (log(ŷᵢ + 1) - log(yᵢ + 1))²) Used for non-negative targets and when relative growth is more important than absolute difference.
MBE Mean Bias Error MBE = (1/n) * Σ (ŷᵢ - yᵢ) Positive values indicate overprediction; negative values indicate underprediction.
R² Coefficient of Determination R² = 1 - (Σ (yᵢ - ŷᵢ)² / Σ (yᵢ - ȳ)²) Explains how much variance is captured by the model; closer to 1 is better.

Advanced Forecast & Model Selection Metrics

These advanced metrics help compare models, validate assumptions, and select the best forecasting approach.

Metric Definition Formula Interpretation
AIC Akaike Information Criterion AIC = 2k - 2 ln(L) Model complexity vs fit; lower is better for comparing candidate models.
BIC Bayesian Information Criterion BIC = k ln(n) - 2 ln(L) Penalizes complexity more strongly than AIC; useful for time-series models.
Theil's U Relative forecast error statistic U = sqrt(Σ (ŷᵢ - yᵢ)² / Σ (yᵢ - yᵢ₋₁)²) Values < 1 indicate forecast outperforms naïve persistence; > 1 suggests underperformance.
Explained Variance Variance captured by the model EV = 1 - Var(yᵢ - ŷᵢ) / Var(yᵢ) Measures how well the model explains the variability of the target.
Pearson Correlation Linear correlation between predictions and actuals ρ = Cov(y, ŷ) / (σ_y σ_ŷ) Values closer to 1 imply strong positive agreement between values.
Spearman Correlation Rank-based correlation between predictions and actuals ρ_s = 1 - (6 Σ dᵢ² / (n (n² - 1))) Useful when monotonic ordering is more important than exact values.

Metric Definitions & Notes

Forecast Accuracy

Accuracy metrics are used to quantify the difference between forecasted values and observed values. Lower error metrics typically mean better performance, but the best metric depends on business goals and scale.

Scale Sensitivity

MAE, MSE, and RMSE are scale-dependent and appropriate when the target unit is meaningful. Percentage-based metrics such as MAPE and SMAPE are better when comparing across different crop prices or market segments.

Model Selection

Information criteria like AIC and BIC are helpful for selecting between ARIMA, SARIMA, and other statistical models without requiring additional validation data. They balance fit and complexity.

Bias & Correlation

MBE measures directional bias. Correlation metrics verify whether the model preserves the trend and ranking of actual values, which is essential for decisions based on forecast direction.

How to Use This Page

Use the metric categories to choose the right evaluation technique for each stage of your agricultural forecasting pipeline:

  • Basic metrics for quick model comparisons.
  • Intermediate metrics for handling percentage errors and growth-based forecasts.
  • Advanced metrics for model selection, time-series validation, and robust production monitoring.
